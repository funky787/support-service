# Отчёт по разработке

Разработано серверное API поддержки на Java/Spring Boot с PostgreSQL и Flyway. Kotlin-модуль считает статистику за период: созданные заявки, распределение по статусам и приоритетам, просроченные открытые заявки и среднее время решения.

## Решения Kotlin

1. `data class SummaryResponse` генерирует методы модели ответа без Java boilerplate.
2. `mapNotNull`, `takeIf` и nullable `Double?` позволяют возвращать `null`, когда завершённых заявок нет, и безопасно пропускать записи без времени закрытия.

## Инфраструктура

Docker Compose с постоянным volume, readiness checks, резервное копирование и восстановление в тестовую базу. GitHub Actions проверяет код и публикует образ после успешных тестов; доставка включается отдельно на учебный стенд.

## Ограничения и что ещё подтвердить

Этот файл фиксирует реализованные исходники, **не результаты фактического запуска**. Перед сдачей заполнить: ссылку на репозиторий, успешный run GitHub Actions, тег образа, адрес стенда, ссылку на health check, показания JaCoCo, результаты backup/restore, дату демонстрации отката и фактические трудозатраты. Не записывать вымышленные результаты.
